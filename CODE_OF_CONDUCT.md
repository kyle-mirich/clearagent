# Code of Conduct

## Our Standard

ClearAgent should be a welcoming place to learn, ask questions, report
problems, and contribute. Be respectful, assume good intent, give actionable
feedback, and focus disagreement on ideas and evidence rather than people.

Unacceptable behavior includes harassment, discrimination, threats, sexualized
attention, deliberate intimidation, publishing another person's private
information, or repeatedly disrupting project spaces.

## Scope

This standard applies in repository issues, pull requests, discussions, review
comments, and other spaces where someone is representing the project.

## Reporting And Enforcement

For ordinary project disagreements, ask maintainers to review the thread. For
sensitive conduct reports, use a private contact method listed on the
maintainer's GitHub profile rather than posting personal details publicly.

Maintainers may edit or remove content and may temporarily or permanently
restrict participation when behavior conflicts with this standard. Reports
will be handled as privately and fairly as practical.
